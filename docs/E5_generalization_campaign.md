# E5 — Generalization campaign

**Status: not started.** Depends on E4.

## What it tests

The full generalisation campaign: 2 contrasted zone pairs + 2 controls
(4 environments total, each derived per `helplessness.envs.dynamics.pairing`),
testing whether the controllability axis found in E3/E4 generalises across
appearance families -- the reason dynamics and appearance are decoupled at
the framework level (see `helplessness.envs.zones`): this campaign needs
to cross them freely.

## Environment

World-model / pixel version, 2 contrasted pairs + 2 paired controls.

## Agent

World model (same as E3/E4).

Not yet defined -- depends on E4's pilot results.
